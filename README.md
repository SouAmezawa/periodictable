Periodic Table
A comprehensive chemistry desktop application built with Python 3 and Tkinter.

Features
Full Periodic Table — All 118 elements with detailed properties (atomic mass, electron configuration, melting/boiling point, density, discovery history, etc.)

Chemistry Tools — Molar mass calculator, equation balancer, CAS lookup, unit converter, pH calculator, electrochemistry and thermodynamics calculators, titration curve simulator

Visualization — Dynamic atomic structure, electron configuration viewer, orbital viewer, 3D molecule models, element discovery timeline

Chemistry Lab — Physics-engine-based molecular collision and reaction simulation

Element Spectra — Emission and absorption spectrum viewer

Multilingual Table — Layout adapts to different writing directions (LTR / RTL / vertical)

Educational Games — Element memory, formula practice, equation balancing, quizzes

Cross-disciplinary Tools — Physics, math, biology, history, geography, arts

Games — Snake, Tetris, Pong, Minesweeper, Avoid White Block

Utilities — World clock, calculator, notepad, drawing board, timer, scoreboard

Plugin System — Load custom Python plugins from ./plugins/ or C:/pt/plugins/

Requirements
Python 3.8+

Tkinter (usually bundled with Python)

Unifont font (auto-install prompt on first run, but here is a bug)

Only Python standard library is used — no third-party packages required.
